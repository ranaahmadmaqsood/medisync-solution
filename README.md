## 🌟 Key Features

- **Kokonut UI Components**: 
  - Real-time generative AI search query simulator (Google Gemini, ChatGPT, Perplexity).
  - Practice Revenue Lift & ROI dial calculator with custom specialty presets.
  - Interactive 3D tilt bento grid covering 6 core healthcare solutions.
- **Bklit UI & Recharts Analytics Engine**:
  - 4-tab interactive dashboard (Patient Acquisition Trajectory, 90-Day Transformation, Practice Authority Radar, and Clinic Capacity Utilization).
- **Interactive Before / After Dual-Mode Visualizer**:
  - Horizontal drag slider & side-by-side view comparing unoptimized clinics against MediSync #1 local 3-pack practices.
- **Live Market Radar Scanner**:
  - Interactive 5-mile local radius scanner identifying competitor clinics and locking onto your practice with live telemetry.
- **5-Step Patient Acquisition Funnel**:
  - Guided interactive roadmap from initial search to confirmed booking.
- **Official Google Forms Audit Integration**:
  - One-click redirect to Google Forms for fast, 60-second practice evaluations.
- **100% Brand-Aligned Aesthetic**:
  - Deep Navy (`#0A2E5C`), Medical Red (`#D62828`), and clean clinical canvas styling.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation
```bash
# Clone the repository
git clone https://github.com/ranaahmadmaqsood/medisync-solution.git

# Enter project directory
cd medisync-solution

# Install dependencies
npm install

# Start development server
npm run dev
```

### Windows One-Click Launchers
- **`run-dev.bat`**: Double-click to start local development on `http://localhost:5173/`.
- **`run-preview.bat`**: Double-click to preview the production build on `http://localhost:4173/`.

### Production Build
```bash
npm run build
```
The optimized production bundle will be generated in `/dist`.
